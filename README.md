# Lộc Phát POS — Windows Releases

Kho công khai này **chỉ lưu bản cài Windows** của Lộc Phát POS phục vụ cập nhật qua Internet.

- Mỗi phiên bản phát hành một GitHub Release có tag dạng `v3.11.54`.
- Tệp bộ cài tên chuẩn: `LocPhatPOS_V31154_Setup.exe` (các bản sau tăng theo version).
- Máy POS tải bản mới từ API cập nhật của Worker, kiểm tra kích thước và SHA-256 trước khi chạy.
- Không đưa dữ liệu bán hàng, khóa bí mật, mã nguồn nội bộ hoặc file cấu hình chứa thông tin riêng tư vào kho này.
